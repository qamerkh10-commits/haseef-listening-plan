# خطة سماع حصيف

خطة استماع يومية من ٩ نوفمبر ٢٠٢٦ إلى ٨ مارس ٢٠٢٧: محاضرتان للانطلاق، وخمس سلاسل، وخمس حلقات بودكاست يوم الجمعة.

- من أين أبدأ؟ — الشيخ أحمد السيد
- تأسيس وعي المسلم المعاصر — م. أيمن عبدالرحيم
- الأمة بين احتلالين — الشيخ أحمد السيد
- صمّام أمان — الشيخ إبراهيم رفيق الطويل
- كن عزيزًا بإسلامك — د. إياد القنيبي
- فقه التصورات — د. نايف بن نهار

افتح الصفحة: https://qamerkh10-commits.github.io/haseef-listening-plan/

كل زر يفتح الحلقة على يوتيوب من دقيقة البداية مباشرة، والتقدّم يُحفظ في متصفحك.
